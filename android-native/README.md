# أكك لايف Offline — Android Native

تطبيق Android أصلي مستقل يعمل دون إنترنت. هذا المشروع منفصل عن تطبيق WebView الموجود في `mobile/` وعن موقع Next.js.

## الهوية

- اسم التطبيق: أكك لايف Offline
- المعرّف: `com.akaklive.offline`
- الحد الأدنى: Android 8 (API 26)
- الواجهة: Kotlin + Jetpack Compose
- قاعدة البيانات: Room فوق SQLite

المعرّف المنفصل يسمح بتثبيت هذه النسخة بجانب تطبيق `com.akaklive.app` الحالي أثناء التطوير والاختبار.

## البناء

افتح مجلد `android-native` في Android Studio، أو نفّذ:

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

سيظهر APK التجريبي في:

```text
app/build/outputs/apk/debug/app-debug.apk
```
